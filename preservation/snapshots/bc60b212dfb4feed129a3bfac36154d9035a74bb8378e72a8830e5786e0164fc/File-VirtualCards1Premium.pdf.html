VirtualCards1Premium.pdf (file size: 353 KB, MIME type: application/pdf)

Original, unmodified one-page Players Committee PDF titled Virtual Set #1 Premium Edition, containing twelve lower-card slips for Virtual Set 1: Legacy (Premium Edition).

Source: VirtualCards1Premium.pdf, Players Committee. Preserved copy: Internet Archive. Printed footer year: 2002. PDF metadata records creation on 3 February 2005; that metadata is not a stated release date.

Original filename: VirtualCards1Premium.pdf. Size: 361,922 bytes. SHA-256: 233bb5bcb8fedf14baaa6a65645e488ec2d1dad34dbefd22570edd6324bf1aeb.

The original bytes are retained unchanged. The twelve card articles use extractions of this sheet, not wiki-made full-card reconstructions.
