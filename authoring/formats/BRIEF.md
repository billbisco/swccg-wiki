## Naming (Bill 2026-10-24)
- Historical constructed pools are named for what was legal: `Premiere - X` (Premiere through set X), `Premiere - Original VSn`.
- A fixed special format (sealed product, closed environment, convention format) uses its originator's exact wording (Decipher's or the PC's), e.g. "Death Star II Closed Environment", "Jabba's Palace Sealed Deck". Other names go in the lead ("The Players Committee calls it …").
- If the format's natural title is already taken by a product or card page, add " (format)".

## Sources and citing
- Every fact gets a `<ref>`. Each URL gets a Preserved copy (a Wayback snapshot you opened). Decipher's site survives only on the Wayback Machine; the cloud shell can't reach it, but the linked PC's shell can: use the `mcp__remote-devices__device_bash` tool with curl, e.g. `curl -s -m 60 -L "https://web.archive.org/web/2001id_/http://www.decipher.com/..."` and the CDX API `https://web.archive.org/cdx/search/cdx?url=decipher.com/tournaments/*&output=txt&fl=timestamp,original&collapse=urlkey&limit=500`. Cite snapshots as `https://web.archive.org/web/<timestamp>/<url>`.

## Page shape
```
'''Title''' is … (one or two sentences: what it is, who defined it, when).<ref…>

* '''Type:''' constructed / closed environment / sealed deck / booster draft / cube / casual
* '''Defined by:''' Decipher (year) / Players Committee / play.swccg.com
* '''Card pool:''' …
* '''In use:''' years
* '''Also called:''' … (only if sourced)
* '''GEMP:''' name and <code>code</code> on each server, or "none"

== Card pool ==        (what is legal; deck size and other deck rules)
== History ==          (when and why it appeared, events it was used for, changes)
== See also ==         (* [[Formats]] and related formats)
== References ==
<references />

[[Category:Formats]]
```
Do not write a Tournaments section: the builder adds it from the event pages.
