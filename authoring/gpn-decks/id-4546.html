 The Last 5 Comments
   Wedge231     Not bad. Use the combo Mob Points if you can. If you're going to use Tat Maul x2, maybe play a copy of Maul's ship, too. I would also switch out Barrier for Stunning Leader. You should be using some anti-evasion type card like Blast Door Controls or They're Still Coming Through. Add a Masterful Move or two as well. The combo version is especially versatile. P-60 shouldn't be in here. Maybe P-59 would work.
   plasma     Looks like a decent huntdown. And No I prefer Huntdown to BHBM.
   Shewski     Definitely add more strategy. This looks a bit dated- HD Dueling should be all the rage with v5. It is a standard HD alright- but I think that Crush is needed more than Mob Pts. Space is usually an afterthought in these decks. Eliminate Carida, and possibly a Chimaera. I'd go with Cor DB instead of BF DB so DMYA can get down a little cheaper. Also, use WMAOP instead of Twilek so you can pull the BF: Bridge. It does look like a BHBM decklist, but it works here as well. Maybe lose 1 Palpy. Bad Feeling Have I (V) could be fun. You could start that instead of Rack (V), and pull Vader's Saber (ds2) and Mara pulls her own. DM's Saber you'd have to get on your own. Actually- I'd run EPP Mauls and try to pull off your Put All Sections combo. Young Fool isn't that great. Consider using MM combos to pull the holotable for more generation. What about some SAC? Good luck!
   Cam Solusar     It would help to put more strategy. Looks pretty by-the-book as far as huntdown goes, which can be a good or bad thing. Either it's the tried and true that always works, or it's the strategy that everyone knows how to counter. The only thing that I can think of is supplying defense from OOC. The last time I played against this deck I happened to have 3x OOC in my deck and was able to place Vader OOP... that sort of ended the game there and then. Use either This Is Some Rescue or Unsalvageable. If there is no OOC in your local meta, then nice, this deck should do well. Also, I would try to squeeze in that (V) Tarkin. Could you replace 1x Blizzard 4 with it? Good luck!
