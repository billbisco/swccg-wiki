 The Strategy
 Back to Top 
How to set up:
1. You can pull two interior sites from deck before activating first turn using I'm Sorry. I pull the Chasm Walkway and the Carbon Chamber.

2. Set up Dark Deal/Occupation ASAP. You can use the Obj to pull everything you need.

3. Key is control of sites. Once you've got the sites, you've got to control them at all cost.

A few card explinations:

Crush The Rebellion: Okay, so I'm not too original. This card pulls I Have You Now and keeps the battle destiny down to two for the opponent.

Secret Plans/IAO: Messes with LS retrevial and helps Imp forfeit, no surprise Nabrun, you can also pull the docking bay for help with Dark Deal/Occupation.

CC: Upper Walkway: Exterior site to plop down Igar in Tempest 1 or Blizzard 4.

Dark Maneuver/Tallon Roll: This card is awesome with the Obsidian TIEs. You will never lose control of the Bespin:CC sector. (Beware of Wedge in Red Squadron 1), great one-two punch!!.

They Must Never Again Leave This City pulls the TIES back if you happen to loose them and oh yeah, let's you deploy Executor for free!!

No Escape: Helps keep the Dark Deal/CC Occupation damage coming.


**Sixty first cards:

If I had room, I'd like to throw in another Destroyer Driod and an Abyssian Ornament for a little retrieval.

Bossk in Bus would be good for a little assist at the Cloud City Sector.

Any suggestions to improve this deck would be appreciated.

No specific match ups at this time as the deck is pretty straight forward.
