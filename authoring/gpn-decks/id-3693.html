 The Strategy
 Back to Top 
Overview: Designed to do what LU(V) does best, deploy lots of cards, this deck isn't going to win by any huge differential. But it's fast, strong, retrieves, and does lots of damage, everything a good deck needs to do. The strategy is standard LU(V): deploy speeders, flip, drain, deploy starships, deploy Frostbite (V), and retrieve.

First Turn: Use Strike Planning to pull Rieekan and Dodonna. Use Echo Base Garrison to pull Luke. Do this before you activate. Use Nick Of Time to pull a Dual Laser Cannon. Deploy Rieekan to the war room and use his text to deploy A New Secret Base. Use ANSB to deploy the Meb Lab and the docking bay. Use the objective's text to deploy a marker site. Deploy Luke to the docking bay (or 1st marker if the docking bay wasn't in your deck). If you have enough force, deploy 2-1B from your deck using the Med Lab.

Second Turn: Use EBG to pull another speeder pilot. Use NOT to pull Desperate Tactics or Attack Pattern Delta. Use ANSB to pull Echo Base Operations or Echo Base Sensors. Use Luke to pull Rogue 1. Reveal Rogue 1 and deploy it with Dack to Luke's site. Deploy a Dual Laser Cannon aboad. Use Rieekan to deploy either Navander or Tigram. Deploy another marker site. Deploy Dodonna if you have enough force and deploy EBO if you can. Deploy EBS if you have it. Have Luke get in the speeder and move it to the 4th marker.

Third Turn: Use EBG to pull another pilot or Bacta Tank. Use NOT to pull a Dual Laser Cannon. Use Luke to pull Rogue 3. Use Dodonna to pull Wes. Reveal Rogue 3 and deploy with Wedge to 3rd or 2nd marker site. Deploy Wes and Dual Laser Cannon aboard. Use Rieekan to deploy either Navander or Tigram.

Forth Turn: Use EBG to pull a pilot or Bacta Tank. Use Dodonna to pull an X-wing pilot. Use Luke to pull a speeder. Deploy another speeder to the 2nd o 3rd marker. Flip your objective.

Mid-Game: Speeders should be set up and EBO on table. Drain with T-47 Battle Formation. Use Dodonna and the objective to get out fighter/pilot matches fast and deploy to Hoth for only 2 force each. Use Rieekan to deploy Haven, then starships and pilots will deploy for free. Use Dodonna to get out I'll Take The Leader, with Bacta Tank on table you can forfeit a fighter at the system and save the pilot and the ship. Use Rieekan to get out Frosbite to retrieve.

Notes: Incom Engineer adds 2 to battle destiny wherever I have an X-wing or speeder. Panic can deploy from reserve deck a fighter/pilot match as a react for free if EBO and Haven on table. Walker Sighting is anit-walker tech and pulls Panic. Power Harpoons and One More Pass dominate walkers betters than the Dual Laser Cannons. Menace Fades limits damage, necessary because this deck is so card intensive.

Please rate and let me know what you think.

Shewski: It is possible to flip on turn two. On first turn reveal Luke to to get Rogue 1 and deploy both at 4th marker. Second turn use Luke to get a speeder and and EBG to get it's matching pilot, and if you drew a pilot or speeder in your starting hand (usually happens) you can reveal it and then you have enough speeders for a 2nd turn flip. However, Dack and Wes are important if you think your opponent is going to come down hard on Hoth, especially with walkers, and can be worth the wait. EBO is awsome! The fighter/pilot matches each deploy -2 (-1 for both pilot and ship), your power is +3, and your drain is +2. Already using the docking bay for keeping the fighters on table with I'll Take The Leader, so all that needs to be added is EBO itself, and there are plenty of characters running around in Echo Base to control the three Echo sites needed to deploy it.

cootees1055: EBO doesn't slow down my flip and provides some great bonuses at Hoth. Nick Of Time is a must for the start because it pulls so many useful cards. Even if I'm not playing against IO(V) I can still deploy awsome speeder beats at my opponent's locations. I was going to use Echo Base Trooper Officer, but he has to be at the 4th marker (unshielded) to use his game text. Falcon and Outrider are overrated (Outrider especially because of Death Squadron (V) now) and you'd be suprised how tough the SE Red fighters can be with all the bonuses from Haven (I know Death Squadron (V) cancels it, but it's really good), EBO, and I'll Take The Leader. Big drain, big power, and if Bacta Tank is on table I can forfeit a fighter and pilot and save the both the ship and the pilot, redeploying the pilot and taking off next turn.

catman421: I've considered using Commander Wedge, but his game text is useless since Nick Of Time (V) pulls One More Pass. Wedge, RSL can cancel a battle destiny with any of the Rogue pilots. I'm glad someone agrees with me about EBO. Space too weak? You'd be suprised at how much power 2 SE fighters have at Hoth with Haven and EBO on table: 5 power for each fighter, +3 from EBO, 2 destinies added to power, and 2 battle destinies. Asuming an average destiny of 3, that's 25 power, and once I've deployed the low destiny cards the high destiny Power Harpoons and One More Pass get drawn more frequently.
