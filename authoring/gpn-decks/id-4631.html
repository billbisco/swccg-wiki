 The Description
This is the Light side deck that I have been playing in tournaments for about the last 3 months. This deck is a matching speeder with some space help to try to drain and retrive with some direct damage as well. It's classic at the moment but dose lend it's self to the open format with a few changes that can be made.

 The Strategy
 Back to Top 
This deck is intresting in the way that I like to run it.
(1)On the end of the first players turn pull Rieekan with strike planning.
(2)On the start of your first turn pull Comander luke with Garsion, Durring control phase look for a weapon with nick of time to see what you have acctivated in your force pile. If A New Scret Base in Reserve deploy Rieekan to war room and pull it to star seting up EBO if it's in the force pile look to flip the objective with pulling speeders to marker sites. Pull Echo docking bay with insurection and med lab with ANSB alsong with EBO. then pull a marker site with the objective.
(3)On your next turn pull zev or hobbie at the start of turn and pull sensors as well. this will help to slow down the dark side should they come to hoth. get ebo set up and drop luke in rouge 1 to 3rd marker. pull Lock with Rieekan to set up the T-47 drains.

After this used the fliped objective to pull your space fleet to hold the hoth system Home One and Haven with EBO is a nice set up. Use Rieekan to pull the regulat Snowspeeders and luke to pull Rogue 3 to pull wedge with Flaps. The reason that chewie's AT-ST is in the deck is to help with frostbite Retiveal and to give Rouge 1 the Ability to wonder off hoth if you need to face like Watto and outher such fun decks.

I Would like to see what people will do with idea's for this deck it's only suffered 2 loss in tournaments so far one to a god draw dark deal deck and a loss to a missplayed sequance that gave the player the game on his part. so it's 11-2 so far. So tell me what you think.
Thanks
