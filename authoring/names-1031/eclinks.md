# Part 3: 2012 European Championship red card links

- **Scope.** 42 deck pages; 33 had red card links (100 distinct names, 131 link instances).
- **Drafted.** 31 pages in `pages/`, listed in `all.tsv`. 98 link instances (71 names) are converted to `{{CardLink|exact title|image|label=…}}`, the same form the sibling lines use.
- **Verification.** Every target title and File exists. I checked them via the API.
- **Left red.** 29 names (33 instances) stay red (listed at the bottom).
- **Pool.** The pool is [[Premiere - Virtual Block 8.1]]: Decipher plus the 2009 realignment of the old V-sets into Virtual Blocks 1–7, plus VB8.1.
  - So I map to the **Virtual Block titles current in 2012**, not the older Original Virtual Set pages.
  - Example: OVS17 "Galen, Secret Apprentice (V)" was realigned as VB4 **Galen Marek, Starkiller** with the same game text. Likewise Black Leader → Juno Eclipse, Black Leader, and Fallen Jedi → Maris Brood, Fallen Jedi.
  - Caveat: sibling 2012 deck pages (MPC, Nationals) link the OVS17 pages instead (44× Galen, 33× Fallen Jedi). They may want the same fix later.
- **Version rule.** A "(V)" in the transcript, or a ticked V box on the sheet, means the VB version. Otherwise the Decipher card.
- **Confidence.** A = name fix or reading checked on the sheet scan. B = sheet reading plausible but the card choice is a judgment call (please glance).
- **Transcription quality.** I checked the scans of Kevin Jaap LS, Chris H LS and DS, Enno Haede LS, Peter Rowlands DS and Kristian Snukke DS. The transcription is poor:
  - Several "names" are invented, e.g. "Aqua Face" = Advantage, "Have Some Have Some" = Home One: War Room, "Coln Rebel Garrison" = Echo Base Garrison.
  - Some blue links are wrong too, which this pass did not touch.
  - Enno Haede's LS sheet is dated **25/03/12**, so it may come from a different event.
  - A full re-transcription of these sheets would be worth a separate pass.
